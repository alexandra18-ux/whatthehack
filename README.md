# Muralium

Стартовый проект веб-платформы для примерки муралов на городские фасады. Сервер работает на Django, интерфейс использует Django Templates и JavaScript, а перспективный рендер выполняется в OpenCV.

## Запуск

### Docker Compose и PostgreSQL

```powershell
Copy-Item .env.example .env
docker compose up --build
```

Откройте [Muralium](http://127.0.0.1:8000/). Перед запуском Compose применяет миграции и загружает три демонстрационных проекта. Для входа в [Django Admin](http://127.0.0.1:8000/admin/) создайте локального администратора.

```powershell
docker compose exec web python manage.py createsuperuser
```

### Windows без Docker

Понадобится Python 3.13 или 3.14. При пустом `POSTGRES_HOST` приложение использует локальную SQLite.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py seed_demo
.\.venv\Scripts\python.exe manage.py createsuperuser
.\.venv\Scripts\python.exe manage.py runserver
```

Адрес приложения — [127.0.0.1:8000](http://127.0.0.1:8000/). Для стабильных сессий между перезапусками задайте случайный `DJANGO_SECRET_KEY` в локальном `.env`. Если ключ пуст, Django создаёт временный ключ при запуске процесса разработки.

## Проверка основного сценария

1. Зарегистрируйтесь и выберите здание на странице «Карта».
2. Откройте редактор. Выберите фасад и эскиз из каталога или загрузите JPEG/PNG. Для демонстрационного редактора оба изображения уже выбраны.
3. Укажите верхний левый, верхний правый, нижний правый и нижний левый углы стены. Углы можно перетаскивать.
4. Нажмите «Посмотреть результат» и сравните исходный фасад и визуализацию.
5. Заполните название и описание, затем отправьте проект на модерацию.
6. В Django Admin откройте соответствующую заявку, проверьте изображения и выберите статус «Опубликован». После сохранения проект появится на главной и в данных карты.

Для отдельной учётной записи модератора включите статус персонала и выдайте право `placements.moderate_placement`. Неопубликованные проекты и их изображения доступны автору и модератору. Исходные загрузки хранятся вне публичных маршрутов, а каталог открывается отдельно от публикации проекта.

## OpenStreetMap

Карта работает на Leaflet 1.9.4 с подложкой OpenStreetMap без API-ключа. По метке можно открыть здание и его опубликованные проекты. Клик по свободной точке подставляет координаты в форму добавления здания. Список зданий и ручной ввод координат доступны при проблемах с подложкой.

По умолчанию используются публичные тайлы OpenStreetMap. Для другого сервера растровых тайлов на данных OSM задайте `MAP_TILE_URL` в `.env` и перезапустите приложение. При смене поставщика проверьте его требования к атрибуции в `static/js/map.js`. [Правила использования публичных тайлов OpenStreetMap](https://operations.osmfoundation.org/policies/tiles/)

Демонстрационные точки расположены в Саратове. Фасады и эскизы сгенерированы как иллюстрации для разработки. Для демонстрации реального города замените их материалами с разрешением на использование. Панорамы относятся к следующему этапу.

## Структура

| Папка | Назначение |
| --- | --- |
| `config/` | Настройки, маршруты и точка входа Django |
| `apps/buildings/` | Здания, фотографии фасадов и API каталога |
| `apps/murals/` | Эскизы и привязка к зданиям |
| `apps/placements/` | Редактор, защищённая выдача изображений, модерация и лента |
| `apps/placements/services/perspective.py` | Проверка JPEG/PNG, нормализация изображения и перспективное наложение |
| `apps/maps/`, `apps/users/` | Карта и регистрация |
| `templates/`, `static/` | Шаблоны страниц, стили и JavaScript |

Режим Compose и встроенный сервер Django предназначены для локальной разработки.

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py test
```
