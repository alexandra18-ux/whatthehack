# Murrralium

Стартовый проект веб-платформы для примерки муралов на городские фасады. Сервер работает на Django, интерфейс использует Django Templates и JavaScript, а перспективный рендер выполняется в OpenCV.

## Запуск

### Docker Compose и PostgreSQL

```powershell
Copy-Item .env.example .env
docker compose up --build
```

Откройте [Murrralium](http://localhost:8000/). Перед запуском Compose применяет миграции и загружает три демонстрационных проекта. Для входа в [Django Admin](http://localhost:8000/admin/) создайте локального администратора.

```powershell
docker compose exec web python manage.py createsuperuser
```

### Windows без Docker

Понадобится Python 3.13 или 3.14. При пустом `POSTGRES_HOST` приложение использует локальную SQLite.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py seed_demo
.\.venv\Scripts\python.exe manage.py createsuperuser
.\.venv\Scripts\python.exe manage.py runserver
```

Адрес приложения — [localhost:8000](http://localhost:8000/). Для стабильных сессий между перезапусками задайте случайный `DJANGO_SECRET_KEY` в локальном `.env`. Если ключ пуст, Django создаёт временный ключ при запуске процесса разработки.

## Проверка основного сценария

1. Зарегистрируйтесь и выберите здание на странице «Карта». Для нового здания введите улицу и номер дома. Подтвердите найденный адрес кнопкой «Создать проект».
2. Откройте редактор. Выберите фасад и эскиз из каталога или загрузите JPEG/PNG. Для демонстрационного редактора оба изображения уже выбраны.
3. Укажите углы стены по часовой стрелке, начиная с верхнего левого. Углы можно перетаскивать мышью или пальцем. Для точной подстройки выберите точку клавишей Tab и сдвигайте её стрелками. Shift со стрелкой сдвигает точку на 10 пикселей фотографии.
4. Нажмите «Посмотреть результат» и сравните исходный фасад и визуализацию.
5. Заполните название и описание, затем отправьте проект на модерацию.
6. В Django Admin откройте соответствующую заявку, проверьте изображения и выберите статус «Опубликован». После сохранения проект появится на главной и в данных карты.

Для отдельной учётной записи модератора включите статус персонала и выдайте право `placements.moderate_placement`. Неопубликованные проекты и их изображения доступны автору и модератору. Исходные загрузки хранятся вне публичных маршрутов, а каталог открывается отдельно от публикации проекта.

## OpenStreetMap

Карта работает на Leaflet 1.9.4 с подложкой OpenStreetMap без API-ключа. Граница населённого пункта «Саратов» используется для фильтрации адресов, зданий и проектов. Координаты для нового здания определяются по адресу. [Граница города в OpenStreetMap](https://www.openstreetmap.org/relation/3955288)

Адресный поиск отправляет запрос в Photon после нажатия «Найти» и кеширует результаты. По умолчанию подключён публичный демонстрационный сервис. Для развёртывания под нагрузкой задайте `GEOCODER_URL` с адресом своего совместимого сервера Photon. [Документация Photon](https://github.com/komoot/photon#demo-server)

По умолчанию используются публичные тайлы OpenStreetMap. Для другого сервера растровых тайлов на данных OSM задайте `MAP_TILE_URL` в `.env` и перезапустите приложение. При смене поставщика проверьте его требования к атрибуции в `static/js/map.js`. [Правила использования публичных тайлов OpenStreetMap](https://operations.osmfoundation.org/policies/tiles/)

Демонстрационные точки расположены в Саратове. Фасады и эскизы сгенерированы как иллюстрации для разработки. Для демонстрации реального города замените их материалами с разрешением на использование.

## Лента и личный кабинет

Лента показывает по одной одобренной работе. Карточка движется за вертикальным свайпом по изображению и за прокруткой двумя пальцами над работой. Стрелки над и под изображением тоже переключают работы по кругу вместе с оценками и комментариями. Имя автора открывает его профиль. После входа можно оставить комментарий и одну оценку от 1 до 5 на работу. Повторная оценка заменяет предыдущую.

В личном кабинете можно поменять ник и загрузить аватар в JPEG или PNG. На личной стене видны все свои работы и статусы. В публичном профиле отображаются только опубликованные.

Рейтинг автора — среднее рейтингов его опубликованных работ с оценками. Каждая такая работа имеет одинаковый вес.

Если проект уже запущен, примените новые миграции командой `docker compose exec web python manage.py migrate`. При запуске через Compose миграции применяются автоматически.

## Структура

| Папка | Назначение |
| --- | --- |
| `config/` | Настройки, маршруты и точка входа Django |
| `apps/buildings/` | Здания, фотографии фасадов и API каталога |
| `apps/murals/` | Эскизы и привязка к зданиям |
| `apps/placements/` | Редактор, защищённая выдача изображений, модерация и лента |
| `apps/placements/services/perspective.py` | Проверка JPEG/PNG, нормализация изображения и перспективное наложение |
| `apps/maps/`, `apps/users/` | Карта и регистрация |
| `templates/`, `static/` | Шаблоны страниц, стили и JavaScript |

Режим Compose и встроенный сервер Django предназначены для локальной разработки.

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py test
```
